キーボード配列とは、どのキーを押すとどの文字が入力されるかの決まりです。Tabの右のキーは、JIS配列でもUS配列でもQを打ち、フランスのAZERTY配列ではAを打ちます。中身のハードウェアは同じで、配列はOSが持つ設定なので、数分で変えられます。キーの刻印はそのまま残ります。

日本で「キーボード配列」というと、JIS配列とUS配列のどちらを選ぶかという話になりがちです。英字の並びそのものを変えるDvorakやColemakも、同じ設定画面から選べます。

キーボード配列にはどんな種類がある？

キーボード配列は、キーの形と数を決める物理配列と、各キーに文字を割り当てる文字配列に分かれます。日本語ではそこに、かなを打つための配列と入力方式が加わります。

キーボード配列の種類と、それぞれが決めること
種類主な例決めること
物理配列JIS配列、US配列（ANSI）、ISO配列キーの数と形、Enterやスペースキーの大きさ
英字の文字配列QWERTY、AZERTY、QWERTZ、Dvorak、Colemak、Workman英字キーにどの文字を置くか
かなの配列JISかな、親指シフト（NICOLA）かな入力で各キーにどのかなを置くか

物理配列はキーボードを買い替えない限り変わりません。英字の配列と入力方式は、OSとIMEの設定でいつでも選び直せます。

JIS配列とUS配列の違いは？

JIS配列とUS配列は、英字がどちらもQWERTYの並びで、記号の位置、Enterとスペースキーの形、日本語入力用のキーが異なります。日本で売られているキーボードの多くはJIS配列（日本語配列）で、海外製のキーボードは一般にUS配列（英語配列）です。

選び方は、何を多く打つかで決まります。かな入力を使う人や、日本語と英字を専用のキーで切り替えたい人にはJIS配列が向きます。英文やプログラムを多く打つ人は、1つのキーの記号が2つまでで、かっこが左右に並ぶUS配列を選ぶことがよくあります。US配列の横長のEnterは、右手の小指をホームポジションに置いたまま押しやすいという評価もあります。MacBookのキーボードは買ったあとで変えられないので、Appleのオンラインストアで注文するときにUSキーボードにするかどうかを決めておきます。

ローマ字入力とかな入力の違いは？

ローマ字入力は「ka」と打って「か」を出すように英字の組み合わせでかなを打つ方式で、かな入力はかなの刻印があるキーを押して1打で1つのかなを打つ方式です。ローマ字入力はQWERTYなどの英字配列の上で動くので、かなの刻印がないUS配列のキーボードでもそのまま使えます。かな入力は打鍵の数が減るかわりに、数字の段まで使うかなの位置を覚える必要があります。

JISかな配列は、覚えやすさを重視して50音順に並べたのが始まりです。4段を使うことがタッチタイピングで速く打つ妨げになるとされ、3段に収めて速さを狙った新JIS配列（JIS X 6004）が1986年に規格になりましたが、広まらずに1999年に廃止されました。かなの配列には、親指のキーと文字のキーを同時に押す親指シフト（NICOLA）もあります。

ローマ字入力では、英字の配列がそのまま日本語の打ちやすさを左右します。Dvorak配列には日本語のローマ字入力向けに手を加えた派生配列もあり、詳しくはDvorak配列のガイドとColemak配列のガイドで扱っています。

海外ではどんなキーボード配列が使われている？

各国の配列は、QWERTYをその国の言語に合わせたものです。ñ、ü、éのような文字を足し、記号を動かして場所を作り、ときにはいくつかの英字を入れ替えます。

Dvorak・Colemak・Workmanなどの代替配列とは？

代替配列は、英語でよく使う文字を中段（ホームポジションの段）に集め、指の移動が減るように英字を並べ替えた配列です。よく知られた4つを比べます。

主な代替配列の比較
配列発表QWERTYから動く文字Z X C VOSへの搭載
Dvorak1932年に出願、1936年に特許AとM以外のすべての英字と一部の記号ばらばらで、3つが右手Windows、macOS、Linux
Colemak2006年17キーそのままmacOS、Linux、Windows 11 24H2以降
Colemak-DH2014年Colemakの変更に加え、D、G、B、H、Mを再配置左手のまま、一部は下段で横にずれるLinux。WindowsとmacOSは配布元のファイル
Workman2010年21文字ZとXはそのまま、CとVは1つずれるLinux。WindowsとmacOSは配布元のファイル

よく引用される数字では、中段で打つ割合はQWERTYが32%、Dvorakが約70%、Colemakが約74%です。Workmanの作者OJ Bucaoは横方向の指の動きを手首の負担と考え、中央の2列で打つ打鍵を自身の計算で約6%に抑えました。同じ計算でColemakは12%、Dvorakは14%、QWERTYは22%です。詳しい比較はColemak・Dvorak・Workmanの比較にあります。

どれも英語の文字の頻度をもとに作られています。たとえばDvorakでローマ字入力をすると、母音に加えて日本語でよく使うKとYも左手側にあるので、左手の打鍵が多くなります。

どのキーボード配列を選べばいい？

多くの人にとっては、手元のキーボードに合った物理配列のまま、英字はQWERTYでローマ字入力をするのがいちばん手間のかからない選択です。どのパソコンも最初からこの設定なので、学校や職場で借りた機械でもそのまま打てます。代替配列は指の移動を減らしますが、速さを比べた研究から大きな差は見つかっていません。1956年にEarle Strongが米国一般調達局（GSA）のために各グループ10人で行った研究は、DvorakがQWERTYより効率的ではないと結論づけました。この研究にはQWERTY側に偏っていたという批判もあります。1990年には経済学者のStan LiebowitzとStephen Margolisが過去の実験を見直し、記録のしっかりした実験ではDvorakの利点はほとんどないか、まったくないとまとめています。

状況別のキーボード配列の選び方
あなたの状況合う配列理由
かな入力で日本語を打つJIS配列かなの刻印と、日本語の切り替えキーがある
ローマ字入力で、いまの配列に不満はない手元のキーボードのままQWERTYどのパソコンでも同じ配列で打てる
英文やプログラムを多く打つUS配列のQWERTY1キーの記号は2つまでで、かっこが左右に並ぶ
指の移動を減らし、ショートカットは残したいColemakかColemak-DHZ、X、C、Vが左手に残る
人差し指を横に伸ばす動きがつらいColemak-DHかWorkmanよく使う文字を中央の列から外している
これからタッチタイピングを覚えるどれでもQWERTYの癖がないので、代替配列に移る負担がいちばん小さい

どの配列でも、速さはどの指がどのキーを受け持つかを覚え、キーを見ずに打てるようになるところから伸びます。まだキーを見て打っているなら、タッチタイピングのガイドとキーボードの指の配置図から始めてください。

キーボード配列を変更するには？（Windows・Mac）

配列はOSの設定で変えられ、いくつも入れておいて切り替えることもできます。キーの刻印は変わらないので、Colemakに切り替えてもキーボードにはQWERTYの文字が残ります。

Windows 11

  1. 「スタート」→「設定」→「時刻と言語」→「言語と地域」を開きます。
  2. キーボードの種類を合わせるには、日本語の横の「…」から言語のオプションを開き、キーボード レイアウトの「レイアウトを変更する」で手元のキーボードに合うもの（JIS配列なら日本語キーボード（106/109キー））を選んで再起動します。
  3. DvorakやColemakを足すには、英語の言語オプションで「インストールされたキーボード」の横の「キーボードの追加」を選びます。英語がなければ先に言語を追加します。
  4. Windowsキーを押しながらSpaceを押すと、入れてある配列が順に切り替わります。

Windowsでは配列が言語ごとに登録されるので、DvorakやColemakを選んでいる間は日本語のIMEが働きません。日本語もDvorakで打つには、レジストリでキーボードの設定を書き換える方法や、DvorakJのような専用ソフトを使う方法が知られています。

macOS

  1. キーボードの種類を合わせるには、システム設定の「キーボード」で「キーボードの種類を変更」を選び、キーボード設定アシスタントでJIS（日本語）など手元の種類を選びます。
  2. DvorakやColemakを足すには、「テキスト入力」の「編集」をクリックし、追加ボタンから英語の入力ソースを選びます。
  3. 日本語入力でもその配列を使うには、日本語の入力ソースの設定にある「英字のレイアウト」で、ローマ字入力に使う配列を指定します。
  4. 入力ソースはメニューバーの入力メニューから切り替えます。

ANSI・ISO・JISやテンキーレス、60%も配列？

これらはハードウェアの形と大きさを表す言葉で、どの形やサイズのキーボードでもここまでの文字配列を使えます。ANSIはUS配列の物理規格で、Enterが横長の1段です。イギリスやヨーロッパで使われるISOは、Enterが縦長で、左Shiftが短くなってその右に1つキーが増えます。JISは右Shift、スペースキー、Backspaceを短くして4つのキーを足しています。見分け方はISOとANSIの違いで説明しています。

テンキーレスや60%は、キーをいくつ残すかを表します。テンキーレス（TKL）はテンキーを省き、60%はさらにファンクションキーの段と矢印などの移動キーも省きます。英字の段はどのサイズでも同じなので、60%のキーボードでもJIS配列やColemakをフルサイズと同じように打てます。

インストールせずにキーボード配列を試せる？

試せます。petitdoigtはブラウザーで動く無料のタイピング練習ツールで、キーの物理的な位置をもとにツールの中で配列を切り替えるので、OSやIMEの設定はそのままでColemak、Dvorak、Workman、AZERTYを打てます。画面のキーボードには選んだ配列の文字が、押す指の色付きで表示されるので、刻印がQWERTYのままでも迷いません。配列は11種類（カナダ・フランス語、US QWERTY、フランス語AZERTY、ドイツ語とスイスのQWERTZ、スペイン語、ラテンアメリカ、Dvorak、Colemak、Colemak-DH、Workman）で、ANSI、ISO、JISの形を手元のキーボードに合わせて描きます。画面の表示は英語で、練習文は英語、フランス語、ドイツ語、スペイン語です。日本語の文章とJISかな配列はありません。

公平に比べるなら、ColemakかDvorakでよく使う英単語を1日10分、1週間打ってから決めてください。最初の数セットは遅くて当然です。stats（統計）画面は配列ごとに指別、文字別の数字を分けて記録するので、まだ時間のかかるキーがわかります。ブラウザーはどの指でキーを押したかを見られないため、ツールは正しい指を示し、押したキーとそのタイミングを測ります。
