速い人と遅い人の差の大部分は、キーとキーの間の時間にあります。アールト大学とケンブリッジ大学の研究者が2018年にオンラインの参加者16万8千人を調べた研究では、上位10%がキーを押していた時間は平均104ミリ秒、下位10%は129ミリ秒でした。次の打鍵までの時間には4倍の差があり、遅い人は481ミリ秒、速い人は122ミリ秒でした。この時間を縮めるには、次にどの指が動くかを考えずにわかるようにして、ミスに使う打鍵を減らします。速い人はさらに、いま押しているキーが戻る前に次の指を動かし始めています。

タイピングを速くする方法：6つのステップ

まず正確さと決まった指の使い方を固め、それから弱点を毎日の短い練習で鍛えます。各ステップの理由と根拠の研究は、このあとの節で説明します。

  1. キーごとに打つ指を1本に決め、毎回その指で打ちます。
  2. 画面から目を離さず、指より1〜2語先を読みます。
  3. ミスがほとんど出ない速さまで落とし、ミスはその場で直します。
  4. 遅い文字の組み合わせと弱い指を見つけ、短いセットで練習します。
  5. 1日数分、楽に打てる速さを超えて打ち、崩れたところを練習します。
  6. 週に1回、同じ種類の文章で測り、傾向を見ます。

速い人は何が違う？

速い人はミスが少なく、前のキーを離す前に次のキーを押すことがよくあります。2018年の研究は、参加者の上位10%（約78WPM超）と下位10%（約26WPM未満）を比べました。

ロールオーバーとは、前のキーがまだ下がっているうちに次のキーを押す打ち方です。参加者全体で速さと強く結びつき（相関0.73）、起きたときは2つのキーが平均約30ミリ秒重なっていました。速い人には、タッチタイピングを習ったかどうかに関係なくこの打ち方が見られました。講習を受けた人は、受けていない人より平均で約5WPM速いだけでした。

アールト大学の2016年の小さな研究は、日常的に打つ30人の手と目をモーションキャプチャーと視線計測メガネで追いました。自己流の人の平均は58.9WPM、タッチタイピングを習った人は57.8WPMです。速さを予測したのは3つの習慣で、同じ文字をいつも同じ指で打つこと、いまの打鍵の最中に次のキーへ指を動かすこと、手をキーボードの上で動かさないことでした。ただし自己流の人は、打っている時間の41%でキーボードを見ていて、タッチタイピストの20%の約2倍でした。

どのキーをどの指で打つ？

キーごとに打つ指を1本決めて、毎回その指で打ちます。下の図の標準的な割り当てでは、それぞれの指が斜めの列を受け持ちます。人差し指は2列ずつ、小指は外側の端、親指はスペースキーです。指はホームポジション（A S D FとJ K L ;）に置き、FとJの小さな突起で位置を確かめます。どちらのShiftを使うかなど細かな点はキーボードの指の配置図で扱っています。

JISキーボードでは、右手の小指が受け持つキーがUSキーボードより多くなります。数字の段に¥、下の段に\（「ろ」のキー）が加わり、@や:などの記号の位置もUSキーボードとは違います。ローマ字入力で長音「ー」を打つ-も右手の小指が数字の段まで伸ばすキーで、「コンピューター」のようなカタカナ語に何度も出てきます。

すでに6〜7本の指で打っているなら、一から始め直す必要はないかもしれません。同じ文字をいつも同じ指で打っているか、画面を見たまま1文を打てるかを確かめ、どちらかができなければ標準の割り当てに切り替えます。Eをあるときは中指、あるときは人差し指で打つやり方では、打つたびに指を選ぶことになります。2016年の研究者たちは、キーごとに指を決めればその選択が消え、手元を見る必要も大きく減ると考えています。一から覚える手順はタッチタイピングのガイド、目線の問題はキーボードを見ないで打つ方法で扱っています。

petitdoigtは画面上のキーボードのキーを打つ指ごとに色分けし、打つたびにその指を強調するので、画面を見たまま割り当てを覚えられます。ただしブラウザーには手が見えません。測れるのは押したキーとタイミングで、正しい指で打つのはあなた自身です。

速く打つには、まずゆっくり打つべき？

はい。ミスがほとんど出ない速さまで落としてください。ミス1つには、打ち間違えた1打鍵よりずっと多くの時間がかかるからです。気づいて止まり、Backspaceを1回か何回か押し、どこまで打ったかを探して打ち直します。2018年のデータでは、ミスとその修正が少ない人ほど速く、著者らはミスをわずかに減らすだけで速さが大きく伸びうると指摘しています。

1行に1〜2語以上直しているなら、指がキーを覚えている速さを超えています。1行が丸ごときれいに打てるまでペースを落とすと、速さはあとから戻ってきます。ミスはその場で直し、速さと一緒に正確さも見てください。仕事で意味を持つのはミスを引いたネットの速さで、計算方法はWPMの意味と計算方法で説明しています。目標と練習法はタイピングの正確さのガイドにあります。

遅い文字の組み合わせを見つけるには？

キーからキーへの移動を1つずつ計り、いちばん遅いものを練習します。速さを支えているのは慣れた並びで、2016年の研究では、でたらめな文字列を打つと実際の文章より速さが約半分に落ちました。2018年の研究では、別々の指や両手で打つ2文字の速さが全体の速さをよく予測し、nnのような同じ文字の連打は速い人も遅い人も速く打っていました。

ローマ字入力では、よく使う組み合わせの中に1本の指で2つのキーを打つものがあり、そこではキーを重ねて打てません。de（左手の中指）、ki（右手の中指）、ju、mu、hy、ny（どれも右手の人差し指）がその例で、「できる（dekiru）」「じゅぎょう（jugyou）」「ひゃく（hyaku）」のような日常の言葉に隠れています。

自分の遅い組み合わせは手と癖によって違うので、測るのがいちばんです。petitdoigtのpairs（ペア）ドリルは、標準のadaptive（適応）モードで打鍵ごとの移動時間を計り、遅い組み合わせとミスの多い組み合わせを中心にセットを組みます。stats画面では、配列ごとに弱い移動を時間と正確さつきで一覧できます。練習文は英語、フランス語、ドイツ語、スペイン語で、画面も英語表示です。どのキーをどの指で打つかは、ローマ字入力と同じです。道具を使わないなら、文章を打って詰まった言葉に印をつけ、その組み合わせで練習の1行を作ります。例：dekiru deguchi denwa dengon。

弱い指も同じように鍛えます。薬指や小指が遅れるなら、キーを1回たたいてホームポジションに戻る短いセットで、その指だけを練習してください。1週間のメニューはタイピング練習メニューのガイドにあります。

ローマ字入力の打鍵数を減らすには？

ローマ字入力では、同じかなを短いつづりで打てることがあります。Google日本語入力の変換表では、「し」はshiでもsiでも、「つ」はtsuでもtuでも、「ち」はchiでもtiでも入力できます。si、tu、tiなら1打鍵ずつ少なく、どれも左右の手が交互になります。「ふ」のfuとhuは同じ2打鍵ですが、huはHとUをどちらも右手の人差し指で打つため、手が交互になるfuのほうが重ねて打ちやすくなります。寿司打のようなタイピングゲームも複数のつづりに対応しています。

1日にどのくらい練習すればいい？

集中した10〜15分を毎日、楽に打てる速さを超えることと弱点に使ってください。Keith と Ericsson が2007年にまとめた熟練タイピストの初期の研究は、1日10〜15分、短く集中して楽な速さを超えて打ち、そこで出てきたミスや遅い移動に取り組むよう勧めています。量を増やすだけの効果はもっと小さくなります。2人自身が大学生60人を調べた研究では、ふだんの1週間に打つ量と速さにははっきりした関係がなく、キーボードを使い始めてからの総量とは関係がありました。いちばん速い人たちは、タイピングの授業を受けたうえで、ふだんから速く打とうとしていました。

15分の練習を5つに分けます。

  1. 準備運動、2分。よく使う単語を楽なペースで、画面を見たまま打ちます。
  2. 苦手な組み合わせ、5分。測って見つけた移動を短いセットで。ミスが重なったらセットを早めに終えます。
  3. 弱い指、3分。いちばん遅い指をたたいてはホームポジションに戻ります。
  4. 速さの挑戦、3分。楽な速さより数WPM上の一定のテンポで文を打ちます。ミスは増えますが、次の段階で整えます。
  5. きれいに締める、2分。ふだんのペースで、ミスゼロを目標に文を打ちます。

petitdoigtでは、この5つがwords、pairs、anchors、highwayの各ドリルに対応します。highwayドリルは一定のテンポを保ち、早すぎるキーを受けつけないので、速さの挑戦をごまかさずにできます。

タイピングが伸び悩んだときは？

速さを抑えている原因を1つ見つけ、そこを意図して練習します。ふだんのタイピングは仕事に足りる速さで止まり、それ以上に押し上げられることはまずありません。Keith と Ericsson は、この自動化にわざと逆らう練習を「意図的な練習」と呼んでいます。2016年の研究者たちも、タッチタイピストが70WPMを超えて保つには何らかの意図的な練習が要るとしています。数字が動かなくなったら、次の順に確かめてください。

  • ミスが戻っていないか。Backspaceがまたほとんどの行に出てくるなら、1週間は正確さだけを目標にゆっくり打ちます。
  • 目が下を向いていないか。数字、記号、長音でキーを見ていないか確かめ、それを含む文章を練習します。
  • 遅い移動が残っていないか。70WPMでは1打鍵が平均約170ミリ秒です。その倍かかる組み合わせがいくつかあるだけで、ほかのキーが届いている速さが抑えられます。
  • 先を読んでいるか。Keith と Ericsson が紹介する実験では、先の文字が見えないようにすると、熟練者の優位がほぼ初心者の水準まで縮みました。目は指より1〜2語先に置きます。

100WPM（e-typingのWPMで約500）を目指すなら、平均120ミリ秒に1打鍵、ほぼ修正なしで打つことになります。2018年のデータで上位10%の平均は約90WPMでした。ロールオーバーは速い人の打鍵の約半分を担っていたので、正確さが保てるようになってから練習してください。自分の速さが全体のどこにいるかはタイピング速度の平均で確認できます。
