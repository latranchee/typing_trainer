ISO、ANSI 和 JIS 说的是键盘的物理形状，也就是每个键的大小和位置，中文键盘圈常叫它“配列”。你打字用的布局，比如美式 QWERTY 或德语 QWERTZ，是运行在这个形状上的软件设置（键盘布局一文专门讲这些）。三种形状的大部分键完全相同，差别都在边缘，集中在回车、左 Shift 和空格键附近，它们改变的是小指要做的事。

ANSI和ISO键盘的区别是什么？

ISO 键盘的回车键竖着占两行，左 Shift 短，字符键比 ANSI 多一个；ANSI 键盘的回车只占一行，左 Shift 一直延伸到 Z。ISO 多出的那个键就夹在左 Shift 和 Z 之间。

竖长的回车还挤走了另一个键。在 ANSI 上，反斜杠键（美式键盘上是 \ 和 |）排在最上面一排字母的末尾，正好在回车上方。ISO 那里没有位置，这个键就降到中间一排，紧挨在回车左边；英式键盘在它上面印的是 # 和 ~。ISO/IEC 9995 键盘标准统计，ANSI 排列有 48 个字符键，ISO 排列有 49 个。全尺寸的美式 PC 键盘有 104 个键，常见的欧洲键盘有 105 个；去掉数字小键盘的 TKL 键盘，ANSI 是 87 键，ISO 是 88 键。

键盘厂商用“u”作单位量键的大小：1u 就是一个字母键的宽度。下表在有资料说明时给出了单位。

哪些国家和地区用 ISO、ANSI 或 JIS？

美国用 ANSI，欧洲几乎都用 ISO，日本用 JIS。Apple 把它的每种语言版本键盘都归入一种形状，所以它的键盘列表能给出一份按语言划分的清单。

中国大陆打中文用拼音输入法，配的是美国标准键盘布局，没有专用的中文键盘，中文维基百科的“键盘布局”词条也这样写。Apple 的中文（拼音）键盘和美式英文键盘形状相同，区别在 Tab 正下方：美式键盘那里是大写锁定键，中文（拼音）键盘那里是“中/英”键。

韩文键盘属于 ANSI 一族，在空格键两边多了两个键：한/영 在韩文和拉丁字母之间切换，한자 把韩文转换成汉字。有些亚洲市场还卖一种 ANSI 变体，回车特别大，同时占满 ANSI 和 ISO 两个回车位置。

形状跟着键盘的目标市场走。在伦敦买的笔记本，把 Windows 或 macOS 换成美式英文以后，键盘照样是 ISO。

怎么分辨自己的键盘是 ANSI 还是 ISO？

看回车键：只占一行的是 ANSI，竖着占两行的是 ISO 或 JIS。还拿不准，就做下面四项检查：

  1. 找到回车键。如果它只占一行，反斜杠键就在它正上方，那就是 ANSI。
  2. 看左 Shift。如果它和 Z 之间隔着一个键，那就是 ISO。英式键盘在这个键上印 \ |，德式键盘印 < > |。
  3. 看空格键两边。短空格键左右印着 無変換 和 変換，退格键旁边还有一个 ¥ 键，那就是 JIS。
  4. 数一数最下面一排字母在两个 Shift 之间有几个键。ANSI 有 10 个，从 Z 到 /；ISO 和 JIS 都是 11 个，巴西的 ABNT2 是 12 个。

macOS 能识别三种键盘类型：ANSI、ISO 和 JIS。插上一个它认不出的键盘时，会自动打开“键盘设置助理”。类型认错了，就会有两个键互换位置，最常见的是 Esc 下面那个键和左 Shift 右边那个键。按 Apple 为 macOS Monterey 写的说明，选取苹果菜单 >“系统偏好设置”，点按“键盘”，再点按“更改键盘类型”，然后按屏幕上的提示操作：助理会请你按下左 Shift 右边的那个键，再让你在 ANSI、ISO 和 JIS 之间选择。

ISO 和 ANSI，哪个打字更好？

没有证据表明哪种形状能让你打得更快：我们没有找到比较 ISO 和 ANSI 打字速度的研究，说某种形状更快的文章也都没有引用研究。两种形状的差别在于小指去按三个键时要走多远：

  • 左 Shift，左手小指。ISO 的左 Shift 是 1.25u，ANSI 是 2.25u，中间的空位由多出的那个键补上。在 ANSI 上练出来的小指如果伸得不够远，本想打大写字母，打出来的却是 \ 或 <。这在右手打的大写字母上最明显，比如 H、J、M，因为盲打的人打这些字母时按住的是左 Shift。
  • 回车，右手小指。在 ANSI 上，回车紧跟在中间一排的 ' 后面。ISO 在两者之间多放了一个键，小指要么沿着中间一排走得更远，要么往上去按回车的上半部分。
  • 反斜杠，右手小指。ISO 把它降到中间一排、回车旁边，比 ANSI 上它在最上面一排末端的位置更近。

Ultimate Hacking Keyboard 的 László Monda 以键的单位比较了两种形状，发现 ISO 上回车和左 Shift 离键盘中心大约远一个单位（他算出来是 20 毫米），反斜杠则近一个单位。他指出，人们每天要按回车和左 Shift 几百次，反斜杠却少得多。

人们会察觉到的失误，多半出在换形状的时候。从 ANSI 换过来，右手小指在中间一排找回车，结果按到 ISO 回车左边那个键（英式键盘上是 #）。从 ISO 换过来，小指往上去够回车的上半部分，按到的却是 ANSI 的反斜杠键。在打算长期使用的键盘上慢而准地重复练习，眼睛看屏幕，这两种习惯都会慢慢消失。

petitdoigt 能画出 ANSI、ISO 和 JIS 三种键盘，屏幕上的键盘可以和你桌上的一致，每个键都涂成负责它的手指的颜色，ISO 多出的那个键也不例外。选好你的键盘形状，打几组单词，看看小指都去了哪里。键盘指法图画出了整块键盘上每个键归哪根手指，打字不看键盘的方法帮你改掉低头的习惯。petitdoigt 目前没有中文界面，会显示英文界面。

键盘布局在 ISO 和 ANSI 键盘上都能用吗？

能：任何布局都能在任何形状上运行，因为每个物理键打出什么字符是由操作系统决定的。唯一要注意的是 ISO 多出的那个键，有些布局把别处没有的字符放在了它上面。

  • ISO 键盘上用美式布局。Windows 的美式布局让多出的那个键也打 \ |，回车左边那个键照常打反斜杠，什么都不缺。
  • ANSI 键盘上用欧洲布局。Windows 的德语布局只在 ISO 多出的那个键上放了 <、> 和 |，法语 AZERTY 和西班牙语布局也把 < 和 > 放在那里。ANSI 键盘没有这个键，这些字符就得靠改键或换布局才能打出来。QWERTZ 和 QWERTY 对比与 AZERTY 和 QWERTY 对比讲了这些布局的其他细节。

欧洲布局还把右 Alt 键当作 AltGr，用来打很多键上的第三个字符：在英式布局里，AltGr 加 4 打出 €。德语布局把 { [ ] } 放在 AltGr 加 7 到 0 上，美式布局则让括号在 P 右边各占一个键，写代码时差别很明显。美式布局在 ISO 键盘上什么都不缺，所以拿到一块 ISO 键盘的程序员，可以保留键盘，只在软件里换成美式布局。

Dvorak、Colemak 和 Workman 只在两种形状共有的区域里重排字母，所以在 ISO 和 ANSI 上表现一样。Colemak-DH 是例外：它用到 angle mod，把左下角那一排键整体左移一位。在 ISO 键盘上，多出的那个键正好接住这次移动，DreymaR's Big Bag of Keyboard Tricks 称它“几乎就是一个备用键”。ANSI 键盘没有这个备用键，所以常见的 ANSI 版本把 Z 挪到最下面一排的中间。petitdoigt 根据物理键位自己套用布局，你不用安装任何东西就能在浏览器里试打 Colemak-DH。Colemak 布局指南讲了这个布局的其余部分。

JIS 键盘是什么？

JIS 是日本使用的键盘形状：一个和 ISO 一样的竖长回车，外加几个打日文用的键。全尺寸 JIS 键盘有 109 个键，比 ISO 多 4 个，比 ANSI 多 5 个。买日版笔记本时就会遇到它：Apple 的日文键盘就是这种形状。

多出的键是从变短的邻居那里挤出空间的。空格键缩短，左边放下 無変換（muhenkan），右边放下 変換（henkan）和假名键：変換 把打出的假名转换成汉字，無変換 保持不转换，假名键在平假名和片假名之间切换。退格键缩成一个单位宽，给 ¥ 键腾出位置；右 Shift 也变短，在斜杠旁边放下一个 ろ（ro）键。左 Shift 保持原长，所以最下面一排字母和 ISO 一样有 11 个键，只是多出的那个键在另一端。左上角那个在美式键盘上打 ` 的键，变成了 半角/全角（hankaku/zenkaku），用来在半角和全角字符之间切换。

字母的位置和 ANSI、ISO 完全一样，所以盲打者的基准键在日文键盘上照样能用，拼音也照常打。变化的伸手动作都在边缘，集中在退格键和右 Shift 附近，拇指要适应一个更窄的空格键。

该买 ISO 还是 ANSI 键盘？

买你的布局需要的形状。如果你主要打拼音，或者用美式英文以及 Dvorak、Colemak、Workman 这类基于美式布局的布局，ANSI 已经提供了你需要的每一个键。如果你要打德文、法文、西班牙文、英式英文或其他把字符放在多出的那个键上的欧洲布局，就选 ISO。用 Colemak-DH 的人可能还是更喜欢 ISO，因为 angle mod 在那里有现成的备用键。

如果你已经能在一种形状上熟练盲打，继续用它，就不必重新练回车和左 Shift。喜欢改装键盘的人还要考虑键帽：Corsair 指出，键帽套装总有 ANSI 版本，却不一定有 ISO 版本，Keebsforall 则把 JIS 键帽的选择评为非常有限。
